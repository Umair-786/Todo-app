# To-Do List

A small browser-based to-do list built with HTML, CSS, and vanilla JavaScript. Add tasks, remove them when they are done, and keep them saved in your browser.

## Features

- Add tasks from the form or by pressing Enter.
- Delete tasks with a keyboard-accessible button.
- Save tasks in the browser with localStorage.
- Show a helpful message if saved tasks cannot be read or stored.
- Responsive layout for smaller screens.

## Run it

Open the index.html file in a web browser. No installation or build step is needed.

## How it works

The app stores tasks in localStorage on the current browser and device. Tasks are not synced between browsers or devices. Clearing this site's browser data removes the saved tasks.

## Files

- index.html — page structure and task form
- style.css — responsive styles
- main.js — task behavior and local storage
